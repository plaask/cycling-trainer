# 预置课程（Preset Workouts）

这 9 个 .zwo 是项目自带的示例课程，**不再打进 APK**。

## 怎么用

1. 安装 App 后，在手机"文档/Documents"目录下新建文件夹 `CyclingTrainer`（可任选位置）；
2. 把这些 .zwo（或任何 TrainerRoad / Zwift 导出的 .zwo）放进该文件夹；
3. 打开 App 的"课程"页 → 点 **选择课程文件夹** → 选中那个文件夹（只需授权一次）；
4. 之后每次启动 App 都会自动读取该文件夹里的课程；新增 .zwo 后点"刷新"即可。
